MODEL & METHODOLOGY

每个结果，都能找到计算依据。

什么是“乐观上限”？

销售利用率 100%、系统可用率 99.5%、单副本输出吞吐量为基准的 1.4 倍、跨副本效率 100%。这是一组乐观规划假设，不是已验证的性能上限，也不是市场销量预测。输入输出比采用负载参考值，不能通过任意增大输入比例创造无成本收入。

产能怎样计算？

完整副本数 = 向下取整（GPU 数量 ÷ 单副本 GPU 张数）。集群输出 TPS = 副本数 × 单副本输出 TPS × 集群效率 × 输入负载修正。测算期输出 Token = 集群输出 TPS × 运营秒数 × 系统可用率 × 销售利用率。输入 Token = 输出 Token × 输入输出比。

输入负载修正 =（1 + 参考输入输出比 × Prefill 权重）÷（1 + 实际输入输出比 × Prefill 权重）。这是解释负载影响的简化模型，权重默认 0.05，不能替代真实压测。缓存只改变计费，不自动增加吞吐量。

吞吐量从哪里来？

H100 和 B200 的基准来自 Lambda 的 MiniMax M2.5 测试。4090、5090、PRO6000 等使用明确标识的规划假设；它们不具备同负载测试可比性，不能凭本页估计数判断硬件性能排名。不同量化、上下文长度、并发及互联会显著影响结果。

“最新价格”是什么意思？

它表示最近一次成功观察到的供应商公开挂牌。观察日期与供应商发布日期分别存储；未知发布日期保持未知。国内供应商报价和大陆交货得到明确区分，海外美元价格不会自动换成人民币混入默认值。国内平台单卡挂牌即使未注明交付地或报价日，也可核对后手动用于预算；香港库存、卡数不明或期现货条件不明只作为线索。自动采购参考要求采集不超过48小时、报价日期不超过14天，并排除拆机、工作站/Max-Q替代服务器及明确不适用的报价；这是系统筛选规则，不代表价格有效期。

月租统一到元／卡／月用于比较；八卡整机按向上取整的整机数量计费。30 天包按每年 365 天均摊，小时价按每月 730 小时折算。报价未说明含税、机房节点、电费及带宽时，保留“待确认”说明。

利润与现金有什么区别？

采购模式：设备采购形成资本支出，预算利润扣折旧；首期现金结余另外扣全部采购支出和押金，再加回非现金折旧。押金不计费用，未假设期末退回或卖出设备。租赁模式：满租费用不随客户利用率下降。公司人员与运营成本按月计提。

数据怎样保留？

本地系统将每日价格及每次采集结果写入持久数据库；GitHub Pages 版本由 Actions 每日采集，把价格历史提交到仓库后重新发布。网页中的“读取最新行情”只读取已发布的数据，不会触发后台采集。同一天同一报价保留当天最新成功观察，不同日期分别留档。输入方案保存在当前浏览器，可导出 JSON 备份；下载版 HTML 可离线测算，离线时不执行抓价，也不会假装自动更新。

下一步如何替换估算？
